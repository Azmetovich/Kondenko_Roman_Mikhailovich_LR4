Лабораторная работа №4

Тема: Разработка и интеграция модулей проекта. Отладка отдельных модулей. Организация обработки исключений.

Описание проекта

В ходе лабораторной работы была разработана библиотека классов Librari на языке C# для выполнения операций с товарами. Реализованы методы расчёта общей стоимости товаров и применения скидки, а также проверка входных данных и обработка исключительных ситуаций.

Структура проекта

Librari — библиотека классов для работы с товарами.

Models — содержит класс Product для хранения информации о товаре.

Interfaces — содержит интерфейс IProductService для определения методов.

Services — содержит класс ProductService для расчёта стоимости товаров и применения скидок.

Exceptions — содержит класс InvalidProductException для обработки ошибок.

ProductTests — отдельный проект для модульного тестирования библиотеки.

Функциональные возможности

Расчёт общей стоимости товаров с учётом количества.

Расчёт стоимости товара с учётом процентной скидки.

Проверка правильности введённых данных.

Создание и обработка исключений с помощью try-catch-finally.

Проверка работоспособности методов с помощью модульных тестов.

Сборка и запуск

Открыть решение Librari.sln в Visual Studio.

Выполнить сборку проекта через Build - Build Solution.

Открыть окно тестирования через Test - Test Explorer.

Нажать Run All Tests для запуска всех тестов.

Проверить результаты выполнения тестов.
